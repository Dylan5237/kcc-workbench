# Arckeep Typography Specification

## Wordmark
The `Arckeep` wordmark is custom vector artwork. Do not re-typeset it with a font. Use the supplied SVG/EPS/PDF artwork.

## Product interface recommendations
- Chinese: Noto Sans CJK SC / Source Han Sans SC or the platform system sans-serif.
- Latin: Inter, Segoe UI (Windows-native), or system sans-serif.
- Use Regular/Medium/Semibold weights; reserve Bold for short emphasis.

## Principles
- Quiet hierarchy; avoid decorative display fonts in product UI.
- Use generous whitespace and clear size/weight contrast rather than heavy color blocks.
- Do not bundle proprietary or system font files with the brand package.
