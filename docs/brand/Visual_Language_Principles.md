# Product Visual Language Principles

This document defines visual character only. It intentionally does **not** define page structure, information architecture, navigation model, component placement, or implementation framework.

## 1. Matte, not metallic
Use flat color and subtle tonal contrast. Avoid gold/chrome/metal materials, brushed textures, bevels, glossy highlights, or luxury black-gold styling.

## 2. Sharp geometry, calm surfaces
The identity is sharp; the interface does not need to be aggressive. Use precise icon strokes and clear boundaries on calm neutral surfaces.

## 3. Warm neutrality
Warm Ivory is the preferred light neutral. Deep Charcoal is a strong text/brand surface rather than a mandatory full-screen background. Olive and Warm Sand are restrained accents.

## 4. Hierarchy through spacing and typography
Prefer whitespace, alignment, scale, and weight. Avoid using saturated color blocks as the primary hierarchy mechanism.

## 5. Continuity cues
Where the product communicates resume/continue/state handoff, use subtle directional cuts, open-ended lines, or progressive transitions. Avoid literal storage/cloud/database metaphors.

## 6. Motion
If motion is used, favor short continuation/reveal transitions: 120-220 ms for micro-interactions, 220-360 ms for state continuation. Avoid flashy elastic effects.

## 7. Accessibility
Text and controls should meet WCAG 2.2 AA contrast where applicable. Do not use Olive or Warm Sand alone for essential status meaning without a text/icon cue.
