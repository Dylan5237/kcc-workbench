# Brand Copy & Naming

- Primary brand: **Arckeep**
- Chinese auxiliary name: **续境**
- Brand line: **留住当下，延续未来**

## Default identity
Use **symbol + Arckeep**.

## When to use 续境
Use only when Chinese naming context materially helps: first product introduction in Chinese, localized documentation, store listing metadata, or formal naming references. Do not add it to every logo usage.

## When to use the brand line
Use as communication copy, not as a permanent logo component.
