Agent 接入边界

工作站不承诺每个 Agent 的能力一致；能获得什么，就诚实显示什么。

接入深度待定义
Claude Code
· 可启动 CLI
· 可传项目目录
· 会话索引待验证
· 不承诺完整接续
Codex
· 可启动 CLI
· 可读会话历史
· 可传工作现场
· 不改造原生载体
Kimi Code
· 可嵌入现有 WebUI
· 可识别工作目录
· 跨项目记忆待探索
· 不替代官方功能
Cursor / DSH
· 可登记项目入口
· 只读产出线索
· 会话不可靠
· 不宣称无缝协作

接入不等于统一改写

同一个项目可以被不同 Agent 使用。工作站优先记录项目、会话、产物和判断之间的关系，而不是要求所有 Agent 都使用同一套聊天界面或配置副本。

项目仍是稳定中心 Agent 能力降级可见 统一记忆按需调用
候选能力只做低打扰提示，不因存在就变成首页功能。
这张原型只验证三件事：
1. 首页是否帮助用户“继续工作”；
2. Session Map 是否足够导航接续；
3. Viewer 是否能把 Agent 结论落到真实产物。
